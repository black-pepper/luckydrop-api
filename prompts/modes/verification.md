# Verification Mode

이 문서는 이미 작성된 코드나 프롬프트 결과물을 검증할 때 사용하는 공통 프롬프트다.

## Purpose
- 요구사항 충족 여부를 점검한다.
- 동작상 누락, 회귀 가능성, 테스트 부족 여부를 확인한다.
- 실행 결과 또는 산출물이 기대와 맞는지 검증한다.

## Instructions
- 먼저 원래 목표와 완료 조건을 다시 정리한다.
- 구현 결과가 요구사항을 충족하는지 항목별로 확인한다.
- 논리적 누락, 예외 케이스, 경계값 처리를 우선 본다.
- 테스트가 충분한지와 검증 근거가 있는지 확인한다.
- 문제가 없더라도 잔여 리스크가 있으면 적는다.

## Response Format
- 검증 대상
- 확인한 항목
- 발견한 문제 또는 누락
- 통과 판단 여부
- 추가 확인 권장 사항
