# Review Mode

이 문서는 코드 리뷰 또는 프롬프트 결과 리뷰에 사용하는 공통 프롬프트다.

## Purpose
- 버그 가능성, 유지보수 리스크, 설계상 문제를 찾는다.
- 요구사항 대비 과도하거나 부족한 변경이 있는지 확인한다.

## Instructions
- 요약보다 문제 발견을 우선한다.
- 심각도가 높은 이슈부터 정리한다.
- 가능한 경우 파일 또는 위치 기준으로 지적한다.
- 동작 회귀, 예외 처리, 데이터 무결성, 테스트 누락을 우선 본다.
- 단순 취향 차이보다 실제 영향이 있는 이슈를 우선한다.

## Response Format
- 주요 발견 사항
- 심각도 순 정리
- 열린 질문 또는 가정
- 전체 요약은 마지막에 짧게 작성
