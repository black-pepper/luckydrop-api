# Development Mode

이 문서는 기능 개발, 버그 수정, 리팩터링, 테스트 코드 작성까지 포함한 개발 작업용 공통 프롬프트다.

## Purpose
- 기능 추가, 버그 수정, 리팩터링을 수행한다.
- 필요하면 테스트 코드 작성 또는 수정까지 함께 수행한다.

## Instructions
- 먼저 관련 파일과 호출 흐름을 파악한다.
- 기존 아키텍처와 코드 스타일을 최대한 유지한다.
- 변경 이유가 드러나도록 최소 범위만 수정한다.
- 새로 추가하는 이름은 기존 도메인 용어와 충돌하지 않게 정한다.
- 테스트가 필요한 변경이면 테스트 코드도 함께 고려한다.
- 테스트는 정상 흐름, 실패 흐름, 경계값을 우선 점검한다.

## Response Format
- 변경 내용 요약
- 영향 범위
- 테스트 또는 검증 내용
- 남은 리스크 또는 확인 필요 사항
